## Headline findings (read these first)

1. **The palette VALUES are already universal.** Every one of the 12 pages uses the same
   ink `#1a1a2e`, muted `#6b7280`, line `#e5e7eb`, accent ink-blue `#4338ca`, bg `#fafafa`,
   good `#166534`, warn `#b45309`, bad `#991b1b`. There is **no color divergence anywhere.**
   What diverges is **variable names, font stack, container, and section-header style.**

2. **The real, dominant shared design system is the report/stop "house style" — NOT
   `business-analytics.html`.** 8 of 12 pages (`problem, audit, data, infra, evals, deploy,
   a2a, signal`) share one coherent system: `Space Grotesk` + `JetBrains Mono`, palette vars
   `--acc/--txt/--dim/--card/--mono/--good/--warn/--bad`, a `.wrap` container, and numbered
   bordered-uppercase section headers (`<h2>1 · …</h2>`). This is the house style to
   converge on.

3. **`business-analytics.html` is the odd one out AND is stale.** It uses the *minority*
   naming scheme (`--accent/--ink/--mut`), **omits `JetBrains Mono`**, has un-numbered
   border-less section headers, and its **content is the OLD placeholder version**
   ("Surface ask / Where AI fits / Success criteria / Build-first") — it even still carries
   the yellow `PLACEHOLDER scaffold … Replace with the handed-in file` banner. **Confirmed:
   the served `/business` is NOT the three-act version.**

4. **NO EVIDENCE that a "three-act" business file exists.** I searched every `.html`/`.md`
   in the repo and the full git history of `presentation/business-analytics.html`
   (`git log --all`). There is no file containing "hypothesis / prioritization / what we
   found / the agent this becomes / glossary". The good three-act content **does not exist
   on disk and was never committed.** It cannot be "swapped in" — it would have to be
   authored. **This needs a decision before Phase 2** (see bottom).

5. **The design system is physically duplicated 10+ times and already drifting.** Each of
   the 8 house-style pages hard-codes its own `<style>`; within them there are **5 distinct
   `:root` blocks** (same core values, different extras/subsets). `hub` and `business` add
   two more naming schemes. There is **no shared tokens partial today** — which is exactly
   the drift the "one tokens block" ask is meant to kill.

6. **`/` (chat) and `/dashboard` are interactive and off the type system.** Both use
   `-apple-system` (no `Space Grotesk`/`JetBrains Mono`) and bespoke var names. Per the
   brief, keep their interactivity — align chrome/typography only, do not flatten.
