Run it yourself

Clone it and it runs in ~5 minutes. No key? The tests still prove the whole system offline — it never crashes, it tells you what to set.
This is the actually-verified path — run from a fresh clone on Python 3.12 (any 3.11+). Not an idealized README: every command and message below was executed and captured.

1 · The 5-minute contract

Copy-paste, in order. Needs git and Python 3.11+.
git clone --branch feat/presentation --single-branch \ https://github.com/aifashionweek-ai/fde-agent-template.git fde-agent cd fde-agent python3.11 -m venv .venv && source .venv/bin/activate # any 3.11+ (verified on 3.12) pip install -r requirements.txt # ~10s, no build steps export ANTHROPIC_API_KEY=sk-ant-... # or skip → run `make check` offline (§3) make demo # serves http://localhost:8000/
Shortcut for the two venv/install lines: make setup (creates .venv + installs).

2 · What you'll see

make demo serves a governed chat at http://localhost:8000/. Two things to try:
READ — no approval

Ask "what does the knowledge base say the process requires?" → you get an answer with citations and a confidence. Reads are safe.

SIDE EFFECT — approval gate

Ask for an action (e.g. reset access) → the run pauses: the UI shows the exact tool call + a proposal hash and waits for Approve/Deny. Nothing executes until you approve.

Verified live: a side-effect request returns status: interrupted with the pending tool call and its proposal hash; approving (bound to that hash) executes it — a tampered hash is REFUSED. Agent proposes, human disposes.

3 · No key? The tests still prove the system

The full invariant suite runs offline — no network, no credentials:
make check # regenerates the tool registry, drift-checks, runs the suite # → 201 passed, 2 skipped (the 2 skipped need model keys; every invariant runs)
It covers the approval gate, authz-before-gate, injection refusal, grounding, and MCP read-only — the properties that make the agent safe to leave running. And if you run the live demo without a key, it prints this and exits cleanly — no traceback:
────────────────────────────────────────────────────────────────────── No model credentials found — the live chat demo needs one to call a model. Fix (pick one), then re-run `make demo`: export ANTHROPIC_API_KEY=sk-ant-... # get a key at https://console.anthropic.com # …or configure Bedrock: set BEDROCK_MODEL_ID + AWS creds and LLM_PROVIDER=bedrock No key handy? Prove the whole system OFFLINE (no network, no key): make check # the full invariant suite: approval gate, authz, injection, grounding, MCP read-only ──────────────────────────────────────────────────────────────────────

4 · Prerequisites

  • Python 3.11 or newer — verified on 3.12. Plus git. macOS / Linux.
  • A model credential is needed only for the live chat demo — ANTHROPIC_API_KEY, or Bedrock (BEDROCK_MODEL_ID + AWS creds + LLM_PROVIDER=bedrock). make check needs none.
  • Nothing else — no Docker, no services, no build toolchain. pip install -r requirements.txt is the only install.
Every command and the no-key message above were run from a fresh --single-branch clone and captured verbatim (J-01) — the numbers (install time, 201 passed, 2 skipped) are measured, not asserted.
